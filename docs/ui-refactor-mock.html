Tick nodes to start sessions. Click a name to edit it, click an ssh … line to copy it, ⋯ or right-click for the rest. Press ? for keys.
What to look at
  • D Starting a session: tick one or more nodes, then Start session in the bar at the bottom (one session per node). Also in the node's ⋯ / right-click menu. The node rows have no start button.
  • F Status chips act when there is an obvious next step: a stopped instance starts, a dead agent is removed, a missing login opens Settings.
  • 1× Click a node or session name to edit it. Click an ssh … line to copy it. A session's name is its ssh host, so its line follows a rename.
  • C ⋯ and right-click open the same menu with the rarer actions.
  • 2× Stopping something that runs arms on the first click and runs on the second. Removing something that is not running is one click.
